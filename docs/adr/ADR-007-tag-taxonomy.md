# ADR-007: Tag Taxonomy and Controlled Vocabulary Strategy

Status: Proposed  
Date: 2026-03-13

## Context

Tagging supports classification, recommendation, and reporting, but uncontrolled vocabularies degrade quality.

## Decision

Use a controlled vocabulary organized by tag type and managed through admin tooling.

Tag types include:
- theme
- mood
- occasion
- scripture
- season
- musical_style
- audience
