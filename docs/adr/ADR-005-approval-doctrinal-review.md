# ADR-005: Approval and Doctrinal Review Workflow

Status: Proposed  
Date: 2026-03-13

## Context

Cadentia requires content governance before recommendation eligibility.

## Decision

Approval records are explicit and typed:

- doctrinal
- editorial
- musical
- licensing

Status values:
- pending
- approved
- rejected
- needs_review

Recommendation eligibility requires the necessary approvals to be approved.
